# Python 3.13 Release Notes

Python 3.13, released in October 2024, introduces significant performance improvements with up to a 7% overall speed increase across benchmarks including PyPy and GraalVM compatibility enhancements. Key features include PEP 698 (stackless threads), improved error messages for common mistakes like missing return statements, better handling of large integers via arbitrary precision optimizations, removal of deprecated `asyncio` behaviors from earlier versions, enhanced debugging tools with new tracebacks showing variable states at exception points, and support for the latest Windows API changes. The release also includes security patches addressing CVE-2024-XXXX vulnerabilities in SSL/TLS implementations while maintaining backward compatibility where possible through deprecation warnings rather than breaking changes.
