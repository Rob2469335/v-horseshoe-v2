### Linked List Node Class
First, let's define our `ListNode` class which represents each node of the [K
linked list.

```python
class ListNode:
    def __init__(self, value=0, next=None):
        self.value = value
        self.next = next

    # Method to print the linked list starting from this node.
    def display(self):
        current = self
        while current is not None:
            print(current.value, end=" -> ")
            current = current.next
        print("None")

# Example usage:
node1 = ListNode(1)
node2 = ListNode(2)
node3 = ListNode(3)

node1.next = node2
node2.next = node3

print("Original List:")
node1.display()  # Outputs: 1 -> 2 -> 3 -> None
```

### Function to Reverse the Linked List
Now, we will implement a function called `reverse_linked_list` that takes t[1D[K
the head of a linked list and returns its reversed version.

```python
def reverse_linked_list(head):
    prev = None
    current = head

    while current is not None:
        next_temp = current.next  # Save the reference to the rest of the l[1D[K
list.
        current.next = prev       # Reverse the link by pointing it back on[2D[K
one node.
        
        prev = current             # Update previous and move forward in th[2D[K
the original list.
        current = next_temp

    return prev
```

### Explanation of the Algorithm
The algorithm works as follows:

1. **Initialization**:
   - `prev` is set to `None`. This variable keeps track of the previous nod[3D[K
node in order to update the links correctly during reversal.
   - `current` starts at the head of the linked list.

2. **Iterating Through Nodes**:
   - In each iteration, we perform three steps:
     1. Save a temporary reference (`next_temp`) to what was originally the[3D[K
the next element after `current`.
        ```python
        next_temp = current.next
        ```
     2. Update `current`'s link so that it points backwards towards its pre[3D[K
previous node instead of forwards.
        ```python
        current.next = prev
        ```
     3. Move both pointers forward:
         - Set `prev` to the current node (`current`) since this will becom[5D[K
become the next "previous" for the subsequent iteration.
            ```python
            prev = current
            ```
          - Update `current` with the saved reference from step one, essent[6D[K
essentially moving onto the next element in the original list structure.
            ```python
            current = next_temp
            ```

3. **Termination**:
   - When there are no more nodes to traverse (`current == None`) we stop i[1D[K
iterating and return `prev`, which now holds a pointer to the new head of o[1D[K
our reversed linked list.

This approach efficiently reverses the direction of all pointers without ne[2D[K
needing additional storage space proportional to the size of the input list[4D[K
list. It operates with O(1) extra memory usage due to maintaining only two [K
temporary variables throughout its execution.
